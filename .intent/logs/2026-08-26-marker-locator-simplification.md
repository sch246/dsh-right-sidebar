# Marker locator simplification

Date: 2026-08-26

The user corrected the first source-region practice: markers primarily locate intrusive semantics for an Agent. They are not a miniature ownership database or an automatic uninstall instruction.

Candidate 7 therefore uses one human-visible package token plus compact `region` and `purpose` JSON on each begin line, and a package-only end line. Realization identity, baseline, exact patch digest, generated mapping, and removal ownership remain in state, lock, and the setup receipt. Validation pairs boundaries per package, so another package may overlap the same source without requiring a synthetic merged owner array. Any mutation or removal still requires Agent inspection of current code, Git, state, lock, receipt, and drift.
